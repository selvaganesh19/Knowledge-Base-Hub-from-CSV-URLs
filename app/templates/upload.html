Upload URLs

Select a CSV or Excel file containing URLs. Each one is harvested, stored in SQLite with its raw HTML, then chunked and embedded into the vector index. Person records are extracted from each page at the end of the pipeline.

Choose a file or drag it here
CSV or Excel (.xlsx) · the URL column is detected automatically
Robots.txt is respected; raw HTML is kept for every page.

What happens next

  1. The file is parsed and a URL column is identified from the header and the values.
  2. Each URL is fetched concurrently, with redirects followed and robots.txt honoured.
  3. Page text is extracted and stored alongside the raw HTML in SQLite.
  4. Text is split into overlapping chunks and embedded into the FAISS index.
  5. An LLM pass extracts structured person records from each page.

Expect some failures

Pages that return 403, redirect away, or render client-side are stored as rows with the reason recorded — they are not silently dropped. A batch always runs to completion even when individual URLs fail.
